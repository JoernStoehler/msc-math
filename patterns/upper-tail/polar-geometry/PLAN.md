# Frozen polar pilot — before scores

Target: a target-free symplectically invariant scalar or two-scalar formula that predicts both generic and product upper tails, and transfers to independently frozen nonregular near-HKO bodies. Failure is useful only if it identifies a mathematical obstruction or clear poor tail performance; no tuning after scores.

Mechanisms compared: (A) affine-only Mahler volume product, attractive via volume inequalities but blind to symplectic orientation; (B) centered polar symplectic operator norm, attractive because it carries all extremal polar pairings and gives a direct HK lower bound on capacity; (C) translation-optimized polar norm, potentially removes a centering artefact but requires numerical convex optimization; (D) full polar action optimization, rejected because it reimplements capacity. Rubrics considered: bulk R² wrongly rewards elongated-body degeneracy, tail rank alone ignores calibration, elegant theorem alone can concern irrelevant low ratios. Select A+B with C only as a bounded centering diagnostic: judge within-bucket tail accuracy, LOO-family transfer, blind nonregular near-HKO accuracy, simplicity and an implication toward a bound.

Features: primal **volume centroid** g(K); centered polar vertices b_i=a_i/(1-a_i·g); alpha=max_ij|omega(b_i,b_j)|; x=log(alpha sqrt(V)); m=log(V vol(conv b_i)). H0 uses x; H1 m; H2 x,m. Fit predeclared degree1 and complete degree2 log-sys polynomials, no feature selection, on all retained bodies. Baselines: constant and ridge linear/quadratic. Folds: leave one exact generator bucket out, deterministic name SHA256 modulo5 holdout; upper decile chosen within each bucket only after prediction. Report generic/product separately, pooled upper decile, per-bucket, relative-error quantiles, Spearman and tail recall. Any fresh near-HKO challenge is wholly held out and receives the all-retained fit unchanged.

The alpha center diagnostic uses at most 8 SHA-ranked rows per exact bucket plus HKO controls, maximizing t subject to t<=log(1-a_i·c)+log(1-a_j·c)-log|omega(a_i,a_j)|. It changes neither the frozen main feature nor the main scores. Expansion requires a genuinely material result within the root's approved budget; no capacity/volume producer.
