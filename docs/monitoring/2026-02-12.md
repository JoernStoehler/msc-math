## Findings

1. **Property tests are 100x+ slower than all other tests combined.** Agents running `cargo test` wait 10+ minutes, almost entirely on 6 property tests. Every other test finishes in <15 seconds.

2. **Resource contention from concurrent test runs.** Multiple agents/sessions can simultaneously run `cargo test`, each spawning CPU-hungry property tests. The `boundedness-fix` worktree had a zombie process consuming 191% CPU for >70 minutes.

3. **Clippy errors exist on main.** `hk2017/src/test_dataset.rs:220-221` has `op_ref` lint violations introduced in commit 3ea2519.

4. **billiard and tube have only placeholder tests.** Not a performance concern, but notable for test coverage.

---

## Suggested Actions

1. **[High priority] Consider marking property tests `#[ignore]`** so that `cargo test` completes in <15 seconds. Property tests can be run separately with `cargo test -- --ignored`. This would dramatically improve agent iteration speed.

2. **[Medium priority] Fix clippy errors** in `hk2017/src/test_dataset.rs:220-221` (trivial: remove `&` from both operands).

3. **[Low priority] Investigate zombie test processes.** The `boundedness-fix` worktree had a long-running test process. Consider whether worktree cleanup should also kill associated processes.

## Suggested Skill Changes

1. Add a note to Check 5 about running per-crate tests to isolate hotspots rather than the full suite (which may exceed timeouts).
