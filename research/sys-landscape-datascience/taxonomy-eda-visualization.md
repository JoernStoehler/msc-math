# Taxonomy: Exploratory Data Analysis And Visualization

Source intent:

- Frozen taxonomy snapshot for exploratory data analysis and visualization adapted from Tukey, *Exploratory Data Analysis*; Cleveland, *Visualizing Data*; and Wilkinson, *The Grammar of Graphics*.
- This file is the external home for picture-based exploratory work, geometric inspection, descriptive summaries, and visual pattern-search methods.

## Exploratory Summaries

- `EDA-SUMMARY-TABLE` Descriptive summary tables
- `EDA-SUMMARY-DISTRIB` Distribution summaries and marginal views
- `EDA-SUMMARY-GROUP` Grouped and stratified summaries

## Scatter / Relation Displays

- `EDA-VIS-SCATTER` Scatter plots and scatter-matrix style relation views
- `EDA-VIS-SMOOTH` Smoothed relation views and trend overlays
- `EDA-VIS-RESIDUAL` Residual and diagnostic plots

## Distribution Displays

- `EDA-VIS-HIST` Histograms
- `EDA-VIS-DENSITY` Density and kernel-smoothed displays
- `EDA-VIS-BOX` Boxplots and robust spread views

## Multivariate And Projection Views

- `EDA-VIS-PROJECTION` Low-dimensional projection views
- `EDA-VIS-COORDPAR` Parallel coordinates and related multivariate displays
- `EDA-VIS-HEATMAP` Heatmaps and matrix displays

## Grammar-Of-Graphics View Construction

- `EDA-GOG-MARKS` Mark / geometry selection
- `EDA-GOG-SCALES` Scale and transformation choice
- `EDA-GOG-FACET` Faceting / conditioning
- `EDA-GOG-LAYER` Layered annotation and overlays

## Likely Use In This Project

- Strongest overlap: visual inspection of geometric families, projection-based exploratory plots, grouped summary displays, and plot-driven failure analysis.
- Weak overlap: polished presentation grammar details unless the thesis later leans on visualization as a method rather than just exposition.
