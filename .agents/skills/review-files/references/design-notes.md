# Design notes

## Device delivery and session lifetimes, 6 October 2026

Chrome availability does not establish Jörn's current device. The default is now a URL in chat; explicit browser opening remains available. Pandoc is required only for Markdown, so PDF/image/HTML delivery no longer depends on it. Missing sandbox setup routes to the project environment owner rather than an unavailable direct runbook/skill caller.

Host sessions append shares without extending the original eight-hour expiry. Sandbox requests replace the previous session; agents must account for an active reader before invoking another request. This difference is retained, not silently normalized during repair. Temporary explicit-file sharing is distinct from the persistent workstation viewer and retained device delivery. No hosting service was changed by this review.

Open question: whether replacing a sandbox session is appropriate for concurrent human reviews. Offline checks cover prerequisites, URL-only delivery and setup failure; current-device viewing and broader remote routes remain unverified.
