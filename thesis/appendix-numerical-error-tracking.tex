The algorithm enumerates all candidate pairs $(S, \sigma)$
and classifies each into one of five categories:
\begin{description}
\item[Skipped.]
  Adjacency filtering
  (Lemma~\ref{lem:transition-feasibility-appendix},
  Remark~\ref{rem:numerical-pruning})
  determines that no minimum-action Reeb orbit has
  the combinatorics~$(S, \sigma)$.
  The pair is not processed further.
\item[Dismissed.]
  The KKT system is near-singular and
  Algorithm~\ref{alg:near-singular-handling} certifies
  that its value is covered by a smaller pair.
  The pair contributes no candidate.
\item[Certified.]
  The KKT system is solved and all admissibility
  predicates return $\textsc{true}$
  (in particular, $\hat\beta_i > 0$ for all $i \in S$
  is decided with certainty).
  The objective value
  $\hat Q = \hat\beta^\top H\,\hat\beta$
  is the value of a genuinely feasible critical point.
\item[Dropped.]
  The pair is solved but its~$\hat Q$ is below
  the current best certified value.
  Whether the candidate is admissible or not,
  it cannot improve the capacity bound,
  so it is discarded.
\item[Uncertain above certified.]
  The pair is solved, $\hat Q$ exceeds the best
  certified value, and at least one admissibility
  predicate returned $\textsc{unknown}$
  (typically $\hat\beta_i \approx 0$).
  The candidate may or may not satisfy the exact
  constraints, so its~$\hat Q$ may come from
  an inadmissible point.
  The stored~$(S, \sigma, \hat\beta, \hat Q)$ enables
  downstream investigation.
\end{description}

\paragraph{Final answer.}
Let $Q_{\text{cert}}$ be the largest certified~$\hat Q$
and let~$\mathcal{U}$ be the set of uncertain candidates
above~$Q_{\text{cert}}$.
If no certified candidate exists, the algorithm reports
only the uncertain candidates and flags the result for
investigation.
Otherwise:
\begin{enumerate}
\item
  $\mathcal{U} = \emptyset$:
  the certified candidate dominates all uncertain ones.
  The capacity is
  $c_{\mathrm{EHZ}}(K) = 1 / (2\, Q_{\text{cert}})$
  with high confidence.
\item
  $\mathcal{U} \neq \emptyset$:
  some uncertain candidate has a higher~$Q$ value.
  The certified value gives a reliable lower bound on the
  maximum~$Q$ (upper bound on capacity):
  $c_{\mathrm{EHZ}}(K) \leq 1 / (2\, Q_{\text{cert}})$.
  If any uncertain candidate in~$\mathcal{U}$ is truly
  admissible, the true capacity is lower.
  The algorithm returns both $Q_{\text{cert}}$ and
  $\mathcal{U}$ for downstream investigation.
\end{enumerate}

\begin{remark}[Empirical error tracking]\label{rem:empirical-errors}
In practice, we track error bounds empirically in the Rust
implementation rather than deriving tight analytic bounds
for every operation.
The implementation tracks the best certified and best
uncertain candidates separately.
The error tracking happens after the SVD step and does not
require modifying the SVD computation itself.
\end{remark}

\paragraph{Second-pass verification (not yet implemented).}
When $\mathcal{U} \neq \emptyset$---some uncertain candidate
dominates the certified maximum---the \texttt{f64} precision
is insufficient to determine the true capacity.
A second pass could resolve the remaining
$\textsc{unknown}$ verdicts by re-evaluating only the
uncertain candidates in~$\mathcal{U}$ at higher precision:
\begin{itemize}
\item \emph{Exact rationals:}
  Re-solve the KKT system for each $(S, \sigma) \in \mathcal{U}$
  using exact rational arithmetic.
  The positivity predicate $\beta_i > 0$ becomes exact,
  resolving the $\textsc{unknown}$ to $\textsc{true}$
  or~$\textsc{false}$.
\item \emph{Extended-precision floats:}
  Re-solve using 128-bit or arbitrary-precision floats.
  The three-valued predicate's tolerance~$\varepsilon_\beta$
  shrinks with precision, potentially resolving the
  $\textsc{unknown}$.
\end{itemize}
In either case, the second pass operates only on the
small set~$\mathcal{U}$ (not on all pairs), making it
affordable even for expensive arithmetic.

The current implementation does not perform a second pass.
Instead, it asserts that no uncertain candidate dominates
the certified maximum: if $\mathcal{U} \neq \emptyset$,
the implementation panics with an error message reporting
the certified and uncertain capacities.
