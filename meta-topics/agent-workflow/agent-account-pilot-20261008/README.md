# Agent-facing account pilot, 8 October 2026

This package preserves the completed, bounded writing-method pilot recovered from
the retired fde8 worktree on 12 October. It is historical evidence, not a selected
thesis account or permission to execute the proposed follow-on programme.

The pilot compared the existing centrally symmetric partner proof packet, that
packet with a short supplement, and a fuller account. All three initial consumers
recovered the proof and rejected removal of central symmetry. The pilot did not
demonstrate a mathematical recovery advantage from rewriting the proof. A source
assessment identified missing numerical and authoring interfaces; revision 2 and
a targeted rerun with the same consumer recovered those additions. This is one
local feedback cycle, with different information in each condition, shared model
lineage, and no measured whole-thesis, human-authoring, cost or correctness benefit.
