# Frozen archival-consumption study

Start with [analysis](analysis.md), [protocol notes](protocol-notes.md), and [preregistered design](design.md). The tested v2 candidate is preserved separately in `packet/`; final production edits were not substituted into this trial.

Cases, criteria, launch order, source/packet hashes and canonical scoring exhibits were frozen before any consumer response. Every answer and both initial/corrected scorer returns are retained. `reader-receipts.json` records exact delivery hashes, source-word accounting and requested ranges; `participant-provenance.json` and `scorer-provenance.json` retain native model/effort, timing and cumulative counters without account metadata or private rollout paths. Recorded full tool outputs are not automatically proof of effective model input; see the delivery-repair account.

The exact private source bundles and full consumer read text remain under the investigator's archival artifact directory. This public subset retains their hashes and neutral inventory plus bounded selected canonical source exhibits, not complete private conversations. Reader configs preserve the exact assigned instructions and allowed paths/hashes. Running the reader requires the original private sources and is not a new authorized experiment.

No model comparison, general reliability or future human-time saving is inferred. The task3 packet-only historical fact is an explicit information confound; its score difference is not credited as an equal-information reasoning gain.
