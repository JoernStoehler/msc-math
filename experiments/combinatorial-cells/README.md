# Combinatorial Cells Package

Orientation doc for `exp-combinatorial-cells` (`experiments/combinatorial-cells`).

This package profiles how combinatorial-type cells and transition data change under dual-vertex perturbations.

Packet map:
- `cell-widths/` — single-facet perturbation widths in dual-space.
- `boundary-characterization/` — boundary event types, crossing logs, transition anatomy.
- `convexity/` — midpoint tests for facet/omega/transition-cell convexity.
- `multiple-crossings/` — budgeted multi-boundary sweeps on representative directions.
- `gradient-discontinuity/` — gradient-angle jumps and cell-width correlation analyses.
- `omega-hypothesis/` — ridge-obstacle hypothesis test and negative results.
- `src/` — shared helpers.

This folder is for local-facing experiment summaries and quick role orientation only.
