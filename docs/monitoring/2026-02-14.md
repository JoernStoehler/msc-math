2. **Test count explosion in geom (+74 tests).** Error-path tests, validation tests, and other additions from the lagrangian-products and viz branches. Despite the explosion, geom's total test time **dropped** 74% (11.1s → 2.93s), suggesting previous tests were inefficient or the new tests are fast.

3. **hk2017 dominance is structural, not a bug.** The 87.5% percentage is high, but the absolute time (37.4s) is reasonable. As long as the full suite stays under 10 minutes, this is acceptable. The dominance will only reduce if other crates add expensive tests (unlikely) or hk2017 tests move to release-only (Check 7 recommendation).

4. **No test duplication or bundling issues.** All reviewed tests have single, clear purposes.
