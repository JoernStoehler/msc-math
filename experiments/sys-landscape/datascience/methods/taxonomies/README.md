# Datascience Method Taxonomies

These files are frozen method-family snapshots used for coverage checks. They
are not repo-state summaries and not thesis evidence.

Use them to answer:

- Does a standard method family exist?
- Which taxonomy ID should a method row cite?
- Which omitted family should be named as skipped, deferred, or inapplicable?

Do not use them to infer what the repo has already run. For current method
status, read `../README.md`.

## Files

- `taxonomy-islr.md`: ISLR-style statistical learning.
- `taxonomy-esl.md`: ESL-style classical statistical learning.
- `taxonomy-murphy.md`: probabilistic machine learning.
- `taxonomy-dfo.md`: derivative-free / black-box optimization.
- `taxonomy-numerical-optimization.md`: numerical optimization.
- `taxonomy-continuation.md`: continuation / homotopy methods.
- `taxonomy-bayesian-optimization.md`: Bayesian optimization.
- `taxonomy-eda-visualization.md`: exploratory analysis and visualization.
- `taxonomy-statistical-inference.md`: statistical inference and resampling.
- `taxonomy-time-series.md`: time-series and sequential analysis.
