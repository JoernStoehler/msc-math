\subsection{Dismissal Error Bound Validation}
\label{sec:dismissal-error}

Remark~\ref{lem:dismissal-error-bound} gives a computable error bound
for each dismissed near-singular system:
the value covered by the smaller pair~$(S', \sigma|_{S'})$ is at least
\[
  \nu_0
    - (\alpha^*)^2\,\|\delta\beta'\|\,
      \Bigl(1 + \frac{\|H\|}{\sigma_C}\Bigr)\,\sigma_j.
\]
We evaluate this bound empirically on the capacity test dataset
(33~polytopes, $F = 5$--$8$) to confirm that the value loss from
dismissal is negligible in practice.

\subsubsection*{Methodology}
For each polytope, we enumerate all $(S, \sigma)$ pairs (with the
production A2 adjacency pruning) and apply the instrumented SVD path.
When a pair would be dismissed by
Algorithm~\ref{alg:near-singular-handling}, we instead continue to
compute~$\beta_0$ via the pseudoinverse and evaluate the error bound.
Pairs where~$\beta_0 \leq 0$ are \emph{trivial dismissals}: no
admissible critical point exists, so dismissal loses nothing.
Pairs where~$\beta_0 > 0$ contribute a non-trivial error bound, which
we compare to the production capacity.

\subsubsection*{Results}
Across 5\,662 evaluated pairs, the experiment found
68~non-trivial dismissals (with computed error bounds) and
1\,675~trivial dismissals.
The non-trivial dismissals occur exclusively in the Lagrangian
products (hypercube and triangle product) and their transformed
variants.

The maximum relative error across all dismissed pairs is
$2.3 \times 10^{-17}$, approximately $0.1 \times$ machine epsilon.
Figure~\ref{fig:dismissal-error} shows that all 68~non-trivial
error bounds cluster at or below machine precision, confirming that
the value loss from dismissal is not merely small but numerically
indistinguishable from zero.
