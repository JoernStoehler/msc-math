\subsection{Dismissal Error Bound Validation}
\label{sec:dismissal-error}

Section~\ref{app:near-singular} showed that
Algorithm~\ref{alg:near-singular-handling} may dismiss near-singular
$(S, \sigma)$ pairs without computing~$\beta_0$, relying on
Proposition~\ref{prop:approximate-dismissal} to guarantee that a
smaller pair covers the value up to the error
bound~\eqref{eq:dismissal-error-bound}.
This experiment evaluates that bound numerically to confirm the
value loss is negligible in practice.

\subsubsection*{Methodology}
For each polytope in the test dataset (33~polytopes, $F = 5$--$8$),
we enumerate all $(S, \sigma)$ pairs that the capacity algorithm
would process.
Whenever a pair triggers the dismiss condition of
Algorithm~\ref{alg:near-singular-handling}, we do \emph{not} skip
it; instead we compute~$\beta_0$ via the pseudoinverse and
distinguish two cases:
\begin{itemize}
\item If no $\beta_0 > 0$ exists, the pair has no admissible
  critical point, so dismissal loses nothing
  (\emph{trivial dismissal}).
\item If $\beta_0 > 0$ exists, the pair would have contributed a
  candidate action value~$\nu_0 = \beta_0^\top H\,\beta_0$
  (cf.\ Lemma~\ref{lem:kkt}).
  We evaluate the error bound~\eqref{eq:dismissal-error-bound}
  and report it as a fraction of~$c_{\mathrm{EHZ}}(K)$.
\end{itemize}

\subsubsection*{Results}
Across 5\,662 evaluated pairs, the experiment found
68~non-trivial dismissals (with computed error bounds) and
1\,675~trivial dismissals.
The non-trivial dismissals occur exclusively in the Lagrangian
products (hypercube and triangle product) and their transformed
variants.

The maximum relative error across all dismissed pairs is
$2.3 \times 10^{-17} \approx 0.1\,\varepsilon_{\mathrm{mach}}$.
Figure~\ref{fig:dismissal-error} shows that all 68~non-trivial
error bounds cluster at or below machine precision, confirming that
the value loss from dismissal is numerically indistinguishable
from zero.
