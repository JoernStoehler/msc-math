# A finite envelope LP for parallel translation covers

Research continuation, 29 October 2026. This is a new implementation route in
this repository, not a claim of literature priority. The unrestricted regular
pentagon partner problem remains open.

## Exact theorem

Let finitely many nonempty labelled point groups `P_0,...,P_(k-1)` in the plane
represent templates by their vertices. Anchor group 0 and translate group j by
`(x_j,0)`, with `x_0=0`. Let `y_0<...<y_(m-1)` be the distinct heights of all
input points, assumed to have `m>=2`. If a point in group j has coordinates
`(a_i,y_(r(i)))`, introduce real variables `L_r,R_r` and `x_1,...,x_(k-1)`.
For `d_r=y_(r+1)-y_r>0`, impose

```
L_(r(i)) <= a_i+x_j <= R_(r(i)),                    for every point i,
d_r (L_r-L_(r-1)) <= d_(r-1) (L_(r+1)-L_r),        1<=r<=m-2,
d_r (R_r-R_(r-1)) >= d_(r-1) (R_(r+1)-R_r),        1<=r<=m-2.
```

Minimize the linear objective

```
(1/2) sum_(r=0)^(m-2) d_r (R_r-L_r+R_(r+1)-L_(r+1)).
```

The optimum equals

```
min_(x_1,...,x_(k-1)) area(conv(union_j(P_j+(x_j,0)))).
```

There are exactly `2m+k-1` variables and `2N+2(m-2)` inequalities for N input
points, and `m<=N`. No shift bound, hull-order list, direction-event list or
iterative cutting-plane tolerance is required by the mathematical model.
All coefficients lie in the ordered field generated by the input coordinates.

### Proof

Linearly interpolate L and R between successive heights. The slope inequalities
say L is convex and R concave. At each sampled height there is at least one
input point, so the point inequalities imply `L_r<=R_r`. Linear interpolation
preserves this order between levels. Thus

```
C={(u,y): y_0<=y<=y_(m-1), L(y)<=u<=R(y)}
```

is convex: it is the intersection of the epigraph of L and hypograph of R with
the horizontal strip. It contains every shifted point. Its area is exactly the
trapezoid objective, which therefore bounds the shifted hull area from above.

Conversely, fix any shifts and take the left/right slice endpoints of their
convex hull. These are convex/concave piecewise-linear functions. Their
breakpoints occur at hull vertices and hence at heights in the input list.
Their sampled values satisfy every LP constraint, and interpolation recovers
the actual endpoints throughout. The objective equals the exact hull area.
These two constructions prove equality of the infima. The LP is feasible and
bounded below by zero, so its minimum is attained, as is the hull minimum.
When `m=1`, all shifted points are collinear horizontally and both minima are
zero; that case is handled separately. Coincident vertices, repeated heights,
horizontal hull edges, zero-width endpoint slices and inactive templates are
all included. No genericity assumption is used.

### Bounded optimal face and contact consequence

Suppose the anchored group has points at two different heights, as every
nondegenerate polygon does. Consider a feasible recession direction, denoted
by dots. Point inequalities give `dot L_r<=dot R_r` at each level. A recession
direction of zero objective has all widths `dot R_r-dot L_r=0`, since all
trapezoid weights are strictly positive. The common endpoint sequence is both
convex and concave, hence `dot L_r=dot R_r=alpha y_r+beta`. The anchored points
at two heights force `alpha=beta=0`; every other point inequality then forces
its group's `dot x_j=0`. Thus zero-cost recession is trivial. Every finite
objective sublevel, in particular the optimal face, is bounded.

Consequently an optimal LP vertex exists. Its active rows span all
`2m+k-1` variables. Only point-incidence rows involve the k-1 shift variables;
active slope rows involve the endpoints alone. The active point rows must
therefore contribute at least k-1 independent relations after quotienting out
the endpoint-only coordinate subspace. This is a precise contact-rank
certificate. It does not imply a forest or that every hull edge is parallel
to a template edge; the incidences are point-to-envelope contacts.

## Why this changes the next experiment

The retained 19 October rehearsal minimized these same directional slices by
supporting cuts in an artificial shift box. Its initial 144 updates hit the
18-cut cap; refinements needed 23--80 more evaluations on selected updates.
This formulation supplies the entire exact slice in one finite LP. A floating
LP solver may discover a basis, after which independent ordered-field primal
feasibility, dual feasibility and equality of objectives certify its value.
A separate exact convex-hull area check verifies the geometric reconstruction.

Fix a direction once and allow each template's perpendicular offset s_j to
vary. Solving this LP eliminates all parallel offsets. The full 18-variable
ten-template problem becomes exactly the minimization of this value function
in nine perpendicular offsets. The resulting function is not claimed convex:
its coefficients and height ordering change with the offsets. Within each
fixed height order, the LP coefficients are affine in the offsets; for a fixed
nonsingular basis its value is a rational function, with polynomial inequalities
describing basis feasibility after denominator signs are fixed. This is a
finite semialgebraic reduction of dimension, not a practical global algorithm
or a proof of the HKO lower bound.

The next decisive mathematical discriminator is whether the nine-variable
value function admits a useful global lower certificate or a below-HKO exact
point. More alternating numerical updates alone would not close that issue.

## Comparison and reading limits

Jung--Ahn, *Smallest Convex Hulls of Polygons*, ESA 2026, §5.1 Lemma 6 already
proves that the parallel-translation area objective is convex and piecewise
linear. Their §5.2 gives an exact event-hyperplane/cutting algorithm for the
same subproblem. The present proof is an extended linear-programming
formulation of that known convex primitive; no novelty claim about convexity,
existence of an exact algorithm or the unrestricted global optimum is made.
The inspected paper's §5.1--5.2 does not present this envelope LP; this bounded
reading is not an exhaustive priority search.
