# Builder smoke fixture

One retained random five-facet geometry and one retained 3×3 triangle-product geometry, copied from the registered `polytope-datasets` cache for the 11 October 2026 data-builder pilot. `retained-input/` and `run-local-input/` are seeded command-schema fixtures; the run-local payload labels are placeholders. `historical-unknown-input/` keeps the source rows without seed/attempt and tests that evaluator metadata remains absent. None of these rows represents a newly run producer.

The three `baseline-*-output/` directories hold JSONL bytes generated by the old commands **before** the builder extraction. `failure-probes/` contains run-local input copies that must fail for missing payload, mismatched sample/payload `sys`, or duplicate provenance ID. `prepare-stats.json` is omitted from exact baselines because it embeds paths and timings.

See the [pilot report](../../../../../meta-topics/repository-organization/inventory/pilots/2026-10-11/data.md) for commands, hashes, results, and independent review. The seed and payload-label caveat is also in [FIXTURE-NOTE.txt](FIXTURE-NOTE.txt).

The repeatable [fixture checker](../../check-builder-fixture.py) builds no
geometry targets: after `cargo build -p exp-polytope-invariant-table --bins`, run
`python3 topics/empirical-studies/polytope-invariant-table/check-builder-fixture.py` from the
repository root. It checks six canonical/compatibility output routes and seven
malformed-input cases, including product facet/source disagreement and missing
run-local sample indices. Outputs and mutated fixture copies live in a temporary
directory and are removed on exit.
