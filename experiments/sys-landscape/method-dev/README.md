# Sys-Landscape Method Development

This directory names the role played by the historical producer folders that are
still useful as method-development packets.

Current examples:
- `gradient-ascent-general/`
- `gradient-ascent-products/`
- `variable-f-ascent/`
- `random-sample/`
- `random-product-sample/`
- `normalized-dataset/`
- `feature-*/`

These folders are not moved here yet. The point of this directory is to make the
intended split explicit while the repo still carries overlapping old and new
surfaces.
