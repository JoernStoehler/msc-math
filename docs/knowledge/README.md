## Using this store

Search by the question, claim, symbol or source path before creating a note.
Keep knowledge with its domain owner when a local README, proof or method packet
already makes it discoverable. Add an entry here when a reusable explanation
crosses owners or would otherwise be repeatedly reconstructed.

Each retained note should explain the question it answers, its authoritative
sources and date/revision, the distinction between observation and synthesis,
its limitations, and what changes would require rechecking it. Link it from
this index. Check its sources before applying it to changed manuscript text.
Merge superseded summaries rather than accumulating contradictory advice.

For example, why a feasible upper section differs from an optimizing capacity
branch belongs here as sourced interpretation; an exact certificate stays with
its producer; "check Chapter 7 next" belongs in coordination; and the exact
human annotation stays with its reviewed input in `docs/history/`. A README is
sufficient for this store; add a skill only for a distinct reusable workflow.
