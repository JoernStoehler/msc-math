# Independent verification material

These are reviewer-produced checks, not the thesis’s programs. They do not modify the source thesis or its repository.

`hko_rows.json` contains the 26 exact assignments recovered from the printed Appendix C. `check_hko.py` reconstructs the weights and derivative certificate in SymPy’s exact algebraic field, using a stationary-value derivative identity rather than the thesis’s explicit feasible-section derivative loop. It verifies exact positivity, closure, objective values, stationarity, symmetry annihilation, ranks and a positive left-kernel relation. It also emits approximate diagnostics, which are not used to decide the exact certificate. The program refuses execution with Python assertions disabled.

Run from any directory:

```sh
python check_hko.py
python check_flow.py
python check_classifier_ranks.py
```

Use the actual path to each script when not in this directory. Dependencies and the versions used in the review are recorded in `requirements.txt` and `review_metadata.json`.

`check_flow.py` independently computes rational return-map determinants for the explicit rows in Proposition 5.6 and several repeated-row specializations. `check_classifier_ranks.py` is only a **floating-point diagnostic** of the finite pentagon enumeration and ranks at one interior angle. It is not an exact replacement for the original Sage classification and does not prove identities over the rotation parameter.

The retained logs were generated by the accompanying scripts. Timings are incidental. The exact HKO result is summarized in `hko_audit_result.json`; `hko_numeric_check.npz` contains approximate matrices for convenient inspection. The metadata records the supplied PDF’s SHA-256 and the external repository identifiers inspected. No claim is made that the observed repository HEAD is the source revision of the supplied PDF.

The analytic replacement proof and exact ridge–capacity identity are in `../03_mathematical_audit.md`; numerical testing is not their proof.
