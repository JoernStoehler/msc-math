# Sys-Landscape Method Development

This directory names the role played by the historical producer folders that are
still useful as method-development packets.

Current examples:
- `gradient-ascent-general/`
- `gradient-ascent-products/`
- `variable-f-ascent/`
- `random-sample/`
- `random-product-sample/`
- `../sys-datascience/produce/`
- `../sys-datascience/prepare/`
- `../sys-datascience/methods/`

These folders are not moved here. The point of this directory is to name the
method-development role while the repo still carries overlapping legacy and
maintained datascience surfaces.
