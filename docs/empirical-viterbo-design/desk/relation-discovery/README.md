## Definitions and validation that mattered

* The repository's named `effective_face_count` is Shannon exp-entropy N1.
  The first screen used inverse-Simpson N2. They are distinct; N1 >= N2
  transfers the proved lower bounds but not the explicit formulas.
* Circulation needs the complete set of genuine ridges. The historical replay
  checks every row has zero ordering failures; thresholding away small edges
  would invalidate the conservation argument.
* Symplectic area is the actual polygon integral of omega, not Euclidean area.
  The independent audit checked the source convention and the factor 1/2.
* The new moment data contain deliberate related descendants and source
  controls, not independent random observations. The candidate bound was
  exploratory and its finite support was never interpreted as validation.
* Rational smooth-body calculations independently support the moment
  counterexample. Reusing the other owner's f64 polygon integrator supplies
  an additional numerical check, not an independent exact certificate.
* Code and numerical checks are reproducible with the commands in the two
  notes. Runtime was on the order of seconds; no long producer or capacity
  call was needed. Exact input hashes and concrete witness IDs are retained.
