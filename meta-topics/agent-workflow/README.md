This topic owns how agents and Jörn carry a selected task to a useful result:
communication, delegation, review and continuity. Active authority comes from
[current user instructions and AGENTS.md](../../AGENTS.md); dated evidence here
explains decisions without reopening historical assignments. Project-specific
skills remain discoverable in [`.agents/skills/`](../../.agents/skills/).

## What the retained evidence supports

The [September process audit](process-audit/REPORT.md) and
[October session-failure account](session-failures-2026-10-03.md), with its
[matched postmortem evidence](session-postmortem-2026-10-04/README.md), explain
particular failures of scope, selection, delivery and integration. Remembering
an objective, checking a local result and having a reviewer do not by themselves
establish that the full task has a functioning next action or is complete.
The comparisons did not demonstrate general reconstruction savings or reliable
prevention by more guidance; consult their limitations before using them to
justify another intervention.

is a historical interface design, not a selected implementation.

owner. This topic does not absorb thesis results because an agent reviewed them.
