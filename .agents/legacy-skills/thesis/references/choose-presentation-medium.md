# Choose The Presentation Medium

Use this reference when deciding whether a reader need is best served by prose,
a figure, a table, a code listing, or another compact display.

Name the reader task and the relationship, comparison, sequence, or evidence
the reader must recover. Compare candidate media by comprehension gained,
likely false inference, page and attention cost, integration burden, and
regeneration cost. Do not create an asset merely because the underlying data
or code exists.

Prefer prose for a short linear explanation, a table for repeated exact
mappings or comparisons, and a figure when spatial, visual, sequential, or
quantitative relationships become materially easier to perceive. Hybrid
solutions are valid when each component has a distinct job.

Choose the medium before polishing it. If a rough candidate does not improve
the named reader task over prose, revise the concept or omit it.
