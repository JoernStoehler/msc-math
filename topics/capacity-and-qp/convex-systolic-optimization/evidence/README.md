# Optional proof record

`squared-scalar-proof.tex` is the earlier exact scalar/logarithmic proof of the sharp planar squared-body inequality. It is preserved as optional evidence and is not included by `main.tex`. The paper uses the shorter all-dimensional two-paraboloid argument in `sections/squared.tex`, followed by the same planar and Finsler consequences. The earlier proof's scoped audit is in `../reviews/squared-mathematics.md`; the new geometric argument's audit is in `../reviews/two-paraboloid-mathematics.md`.
