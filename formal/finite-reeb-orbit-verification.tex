\subsection{Orbit Recovery Validation}
\label{sec:orbit-recovery}

The EHZ algorithm (Algorithm~\ref{alg:ehz}) returns a facet
sequence $S$ and weights~$\beta$.
Base point recovery (Lemma~\ref{lem:base-point-recovery}) reconstructs
the starting point $b = \gamma(0)$ of the corresponding Reeb orbit
on~$\partial K$.
To validate that the recovered orbit is geometrically consistent,
we measure four error metrics corresponding to the conditions of the
following lemma:
\begin{itemize}
  \item \textbf{Closure error}: $\lVert \gamma(T) - \gamma(0) \rVert$,
    where $T$~is the period.
  \item \textbf{On-facet error}: maximum distance of any breakpoint
    from its assigned facet.
  \item \textbf{Inequality violation}: maximum violation of
    $\langle a_i, \gamma(t_j) \rangle \le 1$ across all facets~$i$
    and breakpoints~$t_j$.
  \item \textbf{Action error}: $\lvert A(\gamma) - c_{\mathrm{EHZ}}(K) \rvert$,
    where~$A(\gamma)$ is the symplectic action of the recovered orbit.
\end{itemize}
% Jörn: math approved (9987258) — Lemma lem:finite-orbit-verification + proof
\begin{lemma}[Finite verification of simple Reeb orbits]%
\label{lem:finite-orbit-verification}
Let $K = \{x : \langle a_i, x \rangle \le 1\}$ be a polytope with
facets $F_1, \ldots, F_F$ (dual vertices~$a_i$, Reeb vectors~$R_i$).
A piecewise-affine closed curve $\gamma \colon [0, T] \to \mathbb{R}^4$
with breakpoints $0 = t_0 < t_1 < \cdots < t_m = T$ and
piecewise-constant velocity
is a simple Reeb orbit (Definition~\ref{def:simple-reeb-orbit})
if and only if:
\begin{enumerate}
  \item \emph{Closure:}
    $\gamma(0) = \gamma(T)$.
  \item \emph{Reeb velocity:}
    for each $k = 1, \ldots, m$, there exists a facet index
    $\sigma(k)$ such that
    $\dot{\gamma}|_{(t_{k-1}, t_k)} = R_{\sigma(k)}$.
  \item \emph{On-facet:}
    $\langle a_{\sigma(k)},\, \gamma(t_{k-1}) \rangle = 1$
    for each $k = 1, \ldots, m$.
  \item \emph{Inside $K$:}
    $\langle a_j,\, \gamma(t_k) \rangle \le 1$
    for all $j = 1, \ldots, F$ and all $k = 0, \ldots, m$.
\end{enumerate}
\end{lemma}

\begin{proof}
Conditions (1) and~(2) are part of
Definition~\ref{def:simple-reeb-orbit}.
For~(3): since $R_{\sigma(k)}$ is tangent to $F_{\sigma(k)}$
($\langle a_{\sigma(k)}, R_{\sigma(k)} \rangle = 0$),
the inner product
$\langle a_{\sigma(k)}, \gamma(t) \rangle$ is constant on the $k$-th
segment. Hence $\gamma(t) \in F_{\sigma(k)}$ for all
$t \in [t_{k-1}, t_k]$ if and only if it holds at~$t_{k-1}$.
For~(4): on each segment, $\langle a_j, \gamma(t) \rangle$ is
affine in~$t$, so it attains its maximum at an endpoint. Since $K$ is
convex, $\gamma(t) \in K$ for all $t$ if and only if
$\gamma(t_k) \in K$ at every breakpoint.
\end{proof}

The four error metrics measure how closely conditions~(1), (3),
and~(4) of Lemma~\ref{lem:finite-orbit-verification} are satisfied
numerically. Condition~(2) holds by construction, since the orbit is
reconstructed from~$(S, \beta)$ using the facet Reeb
vectors~$R_{\sigma(k)}$.
