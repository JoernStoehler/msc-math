# Sys-Datascience Coordination

This directory contains the durable handoff between data-science phases. It is
not a process log, prompt library, launch queue, or second source for experiment
results.

Read `exploration-result.md` before demonstration/polish or reopening research.
Generated metrics and packet-local interpretation remain under `../methods/`;
producer and prepared-table contracts remain under `../produce/` and
`../prepare/`.

The July 2026 recovered checkpoint contained autonomous-loop instructions,
prompt templates, workflow probes, temporary ownership registries, topic
ledgers, intermediate wave syntheses, and proposed compute packets. Their
surviving evidence boundaries and next-phase inputs were consolidated into the
exploration result. The original material remains available in git history at
`bb0e538e`; it is not current execution state.
