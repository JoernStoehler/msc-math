# Legacy Thesis Source Material

Files in this directory are source material only.

They are not active thesis text and are not input by `thesis/main.tex`.
Do not polish these files in place. When a claim, proof, TODO, source pointer,
or caveat is useful for the active thesis, copy it into the relevant active
section file and adapt it there.

The active thesis scaffold lives in the `.tex` files directly under
`thesis/`. Those files may intentionally contain only headings, labels, and
local TODO/context comments.
