# Sys-Datascience Parked And Rejected Ideas

Use: rediscovery surface for sys-datascience ideas that should not appear on
the current session-decision board. This file exists so future agents can tell
that an idea was considered without treating it as active work. It is not a
queue, launch board, active-work registry, belief ledger, or source of
experiment metrics.

Move an idea back to `next-session-candidates.md` only after a topic owner or
surface scout names the current thesis milestone it would affect and why it now
beats the active alternatives.

Currently rejected as standalone sessions unless a topic owner reopens them:

- blind large random runs as hit searches;
- larger single-feature ridge-only scale-up;
- seed-effect studies;
- old ascent/continuation/local-behavior work;
- generic neural/RL/MCMC/time-series families without a new source interface.
