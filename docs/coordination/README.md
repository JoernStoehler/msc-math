# Project coordination owner

Project coordination is maintained under [project management](../../meta-topics/project-management/README.md).
Read the [coordination contract](../../meta-topics/project-management/coordination.md) for field semantics, ownership, authorization and supervision.

- [Current state](../../meta-topics/project-management/current.json) owns selected work, decisions and current resource observations. The former local `current.json` path is a relative symlink, not another registry.
- [Thesis obligations](../../meta-topics/project-management/thesis-work.md) own the detailed backlog.
- [Continuation constraints](../../meta-topics/project-management/handoff.md) own the handoff.
- [Generated graph](../../meta-topics/project-management/graphs/tasks.svg) projects canonical state; edit the registry and regenerate it.

[The pre-migration snapshot](../history/coordination/current-state-before-pm-migration-2026-10-12.md) retains removed dated resource/change accumulation. Historical plans do not authorize work.
