# Legacy Thesis Source Material

Files in this directory are source material only.

They are old thesis prose and thesis-local notes. Treat them as stale and
mixed paragraph by paragraph: some claims, proofs, TODOs, and source pointers
may still be valuable, but the files are not current thesis structure and do
not define publication-ready text.

They are not active thesis text and are not input by `thesis/main.tex`.
Use `$thesis` and its legacy-import reference before adapting useful material
into an active owner. Do not polish these files in place.

`migration-findings.md` is a legacy-era thesis/code mismatch inventory. It may
still be useful before importing old algorithm, numerics, or tube prose, but it
needs revalidation before driving current work.
