# Selected experiment findings

This is a grep-friendly semantic navigation view. It is intentionally
selective: absence from this file is not evidence that the repository lacks
a related result, counterexample, obligation, or experiment. Start with the
exhaustive physical inventory in `experiments/README.md`, search the
repository, and confirm every entry at its named source before relying on it.

Each bullet keeps the question, bounded answer, exclusions, status, search
terms, and source route together. Update an affected bullet when its source
changes materially; stale source matches are preferable to an unsearchable
relationship, but stale claims must be corrected when found.
