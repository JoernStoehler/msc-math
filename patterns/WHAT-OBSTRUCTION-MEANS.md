# What a proved obstruction would mean

Suppose we propose predicting a body's systolic ratio using only a geometric
measurement `X`. An exact obstruction is **two bodies with the same `X` but
different ratios**. No formula that uses only `X` can return both exact answers.
That still allows `X` to correlate well with the ratio on a sample.

A concrete example already available here uses the full vertex-moment tensor
through degree four. For two regular pentagons, rotating one factor leaves all
those moments unchanged. Yet the known exact capacity formula gives ratios

\[
\frac{5+2\sqrt5}{10}\approx0.94721
\quad\text{and}\quad
\frac{3+\sqrt5}{5}\approx1.04721
\]

at two relative positions. Thus those moments alone cannot even tell which
side of **one** the ratio lies on. The [short proof and precise vertex
measure](features/REPORT.md#1-exact-moment-obstruction-and-first-angular-information)
make this an example we can prove, rather than a hypothetical one.

This obstructs that particular representation. It says nothing against a
better function of symplectic two-face areas, an angular descriptor or a
weighted ridge sum. Its research use is to discard an insufficient input set;
Jörn's rating of that kind of negative result was 1, below a useful upper-tail
predictor (about 2, potentially 3 if it leads toward a global-maximality conjecture).
The pentagon capacity formula itself was already known in this repository.
