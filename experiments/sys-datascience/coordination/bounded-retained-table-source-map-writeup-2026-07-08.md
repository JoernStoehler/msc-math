## Draft Section Shape

### Opening

The data-science search component is deliberately reported as a finite,
reproducible method table. The retained table consists of random generic
polytopes and random Lagrangian-product polytopes under the producer contract
described in the experiment packet. Each row has already been evaluated for
`sys`; method packets therefore answer two bounded questions: whether the
retained table contains a new `sys > 1` example, and whether the observed
features suggest a candidate-selection rule strong enough to justify an
independent generated-candidate test.

### Result

In the current retained table, no trusted row has `sys > 1`; the largest
observed value is `0.86258589584944`. The closed method packets also do not
validate a generated-candidate proposer. This is a bounded negative result for
the named retained table and method packets, not a statement that all random
polytope distributions or all data-science methods fail.

### Method Coverage

The method packets include direct target scans, descriptive tail summaries,
association screens, projection and anomaly diagnostics, supervised ranking,
tail-rule mining, and the P2 missing-baseline packet. P2 adds sparse/shrinkage
linear models, gradient boosting, high-tail classifiers, and feature-family
ablations. These methods find strong held-out in-table signal, but because the
rows have already been evaluated, this signal is explanatory and diagnostic
rather than a validated construction method.

### Geometric Diagnostic

The strongest empirical coordinate is the family of symplectic two-face area
summaries. P2 and the mechanism-discriminator packet both point to ridge
symplectic-area features as carrying substantial high-tail information. The
safe interpretation is narrow: low ridge magnitude is a bucket-local empirical
signal with a controls caveat. Product and combinatorial structure remain
important confounders, and concentration summaries are only diagnostic seeds.

### Tail And Scale-Up

The tail packet supports caution about blind scale-up. Zero positives in the
retained table are a source-backed fact, but posterior predictions from zero
positives depend heavily on the prior and tail extrapolations disagree by model
class. A large blind run would therefore be a model-dominated probe, not a
calibrated hit search.

### Omitted Or Future Work

The bounded result leaves several stronger claims open:

- broader random-distribution or producer-axis claims need a separate producer
  packet, currently represented only by the high-complexity bucket-extension
  candidate from P3;
- positive generated-candidate proposer language needs a rule frozen before
  independent `sys` evaluation;
- calibrated density or hit-rate language needs stronger tail/model evidence;
- mechanism theorem language needs mathematical proof or a much sharper
  falsifiable geometric claim.
