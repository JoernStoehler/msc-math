# Monthly Git checkpoints

One file here records the last visible `main` snapshot of one repository month.
Each checkpoint combines the commit identity, changed-file scope, monthly
resource totals, and a concise interpretation of what changed for thesis use.

These are evidence records consumed by the canonical
`../project-efficiency-analysis-2026-07-12.md`; they are not separate reports.
They are intentionally one file per month so a future agent can inspect one
checkpoint without reopening the entire Git history.

There are no checkpoint files for 2025-09 through 2026-01 because the visible
Codex archive begins before the repository history available for this analysis.
Those months remain resource-only in the canonical report.
