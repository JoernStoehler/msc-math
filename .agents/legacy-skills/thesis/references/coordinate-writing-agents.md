# Coordinate Writing Agents

Use this reference before distributing substantial preparation, drafting, or
review work among agents.

Main owns the cross-chapter reader path, explanatory placement, dependency
order, source-status decisions, and final synthesis. Delegate bounded work
whose output main can evaluate without adopting the worker's hidden model of
the chapter.

After the desired result, reason for delegation, and fresh-recipient choice are
established, use `$subagent-prompting` to construct or review the bounded
assignment. This file supplies writing-specific task inputs; it does not
duplicate the general prompt and return contract.

Parallel preparation is useful when tasks have distinct questions or source
surfaces: source location, citation checks, proof review, experiment-packet
assessment, or cold-reader review. Avoid parallel full prose drafts across
tightly coupled chapters before shared conventions and explanatory placement
are stable; they tend to duplicate motivation and create incompatible local
narratives.

Assign a preparation worker a named downstream decision, not “gather everything
relevant.” Assign a prose writer a reader state, bounded passage, primary source
route, surrounding text, claim boundary, and owned editing surface. Tell every
worker that other agents may be changing the worktree and that it must not
revert their work.

Before scaling an unfamiliar writing workflow, produce one representative
bounded passage and review whether it is reusable as a new starting point. If
it fails, change the input, decomposition, writer prompt, or task ownership
before launching more writers. Do not amortize an untested failure mode across
an entire chapter set.

Separate reviews when their failure modes differ materially. Mathematical
correctness, source strength, reader understanding, and rendered presentation
can crowd one another out. Combine them only when one reviewer can genuinely
perform distinct passes on the relevant evidence.
