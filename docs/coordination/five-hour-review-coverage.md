## Numerical preflight

Source: `crates/symplectic/tests/public_capacity_api.rs`.

Commands:

```sh
timeout 120s cargo test --offline -p symplectic --test public_capacity_api scalar_value_requires_the_requested_relative_accuracy -- --exact
timeout 60s cargo test --offline -p symplectic --test public_capacity_api general_window_matches_complete_exact_enumeration -- --exact
```

Both passed. Initial compile: 30.74 seconds; first test: 0.04 seconds.
Second test: 7.92 seconds, after a 0.12-second cached build.
Only normal Cargo build output was written; tests perform their checks in memory.
No retained evidence producer was rerun.

The first uses the existing simplex's binary64 input with
`capacity_from_dual_vertices`, checks scalar acceptance at relative tolerance
`1e-10`, refusal at zero tolerance, and compares to exact minimizer action for
the same represented input. The second compares the general minimizing words
and action window against complete exact enumeration for the existing
symplectic-triangle-square fixture. These are finite checks, not proof of every
solver claim. They establish a bounded existing fixture/API/comparator path.
The future numerical worker must retain actual input bits and bounds in its
example receipt; the preflight does not pretend that artifact already exists.
