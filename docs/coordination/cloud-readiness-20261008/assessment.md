## What “repo alone” can reasonably mean

Recommend the already selected **claude.ai cloud microVM** as the primary acceptance target. A clone supplies project instructions, code, selected thesis assets, producer commands and retrieval metadata. Normal software installation, package-network access, repository access and an authorized agent account remain environment prerequisites. They are not hidden project state. Model and effort remain environment-owned under Jörn's existing choice.

There are two useful data contracts. The recommended one is **clone plus declared authenticated retrieval**: R2 credentials are supplied privately when a task needs a registered input. A literal **no project credentials at all** contract also supports PDF compilation and ordinary Rust work, but authenticated bulk-data reproduction would then need a public read route or a supplied data bundle. Neither exists as the general declared cloud retrieval route today. Changing data access/publication is a separate choice, not an implication of this assessment.

Require core source editing/building, task-specific input recovery, independent message review on the actual agent surface, and an inspectable return of files/results. Treat live workstation messaging, tailnet dashboards, Hypothesis hosting, workstation telemetry and reset operations as conditional capabilities. This is a recommendation for the support contract, not recorded human acceptance or permission to remove those workflows.

## Codex Cloud is a separate target

Official documentation now distinguishes [current Cloud environments](https://learn.chatgpt.com/docs/environments/cloud-environments) from [Codex Cloud (Legacy)](https://learn.chatgpt.com/docs/environments/cloud-environment). Repository skills are available in current cloud tasks; personal computer skills are not synced. Its environment publication, access and network settings remain service-side prerequisites. The repository's dated setup/maintenance settings correspond to the legacy route; their current external configuration was not inspected here. Do not silently apply that recipe to current Cloud or treat service settings as delivered by Git.
