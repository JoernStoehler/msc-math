# Design Tables, Listings, And Compact Displays

Use this reference when creating, materially editing, or reviewing a
thesis-facing non-figure asset that requires design judgment.

Organize a table around the reader's mathematical, evidentiary, or proof
obligation unless source order is itself meaningful. Make repeated fields and
comparisons directly readable; remove columns and precision that do not serve
the task.

Treat code listings and witness excerpts as explanatory selections rather than
source truth. State whether the display supports proof audit, empirical
orientation, a caveat, a compact fact lookup, or another named use. Include it
only when surrounding prose establishes that reader need.

Check the facts against their owner and apply `manage-publication-assets.md`
when the display is generated. Inspect the final PDF at its intended size;
source correctness does not guarantee readable ordering, line wrapping,
emphasis, or density.
