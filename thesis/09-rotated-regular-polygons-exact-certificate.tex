It remains to prove the lower bound on the open half-domain. By
Theorem~\ref{thm:lagrangian-product-finite-enumeration}, the lower-bound
problem for this Lagrangian-product family is exhausted by the two- and
three-bounce candidates described below. The remaining task is to verify a
finite collection of exact algebraic statements. The verification is
implemented in SageMath. The successful run is not an independent proof of the
theorem; it is the executable certificate that the finite checks required after
this reduction all pass.

The source and full transcript are in
\path{experiments/regular-products/pentagon-rotation-formula-proof/}:
\begin{itemize}
  \item \path{executable_proof.sage.py},

\end{itemize}
The script computes the active branch in the same exact framework: the function
\texttt{assert\_formula\_checks} solves the KKT branch for the intended sigma,
asserts the displayed capacity formula for that branch, and checks the constant
used to convert it to the systolic-ratio formula.

\begin{certificatecheck}
\noindent\textbf{Certificate check: active branch.}
The preflight stage reconstructs the branch
\((3,8,1,0,5,6)\) over the same exact field as the lower-bound certificate. It
checks the KKT equations, positivity of the multipliers, positivity of the
quadratic value, the displayed action formula, and the constant converting the
action to the displayed systolic-ratio formula.
\end{certificatecheck}

The certificate uses the parameter
\[
  t=\tan(\theta/2).
\]
The unrotated pentagon already has coefficients in the real subfield of
\(\mathbb{Q}(\zeta_{20})\), and the identities
\[
  \sin\theta=\frac{2t}{1+t^2},
  \qquad
  \cos\theta=\frac{1-t^2}{1+t^2}
\]
make all branch expressions rational functions of \(t\) over that coefficient
field. Sage uses exact algebraic root isolation to compare interior roots and
the boundary values \(0\) and \(\tan(\pi/20)\) when constructing the open
cell decomposition of \(0<t<\tan(\pi/20)\).

\begin{certificatecheck}
\noindent\textbf{Certificate check: exact sign decisions.}
Every sign assertion used below is reduced to a rational function over this
ordered algebraic coefficient field. The implementation cuts
\((0,\tan(\pi/20))\) at the exact roots and poles of the relevant numerator and
denominator polynomials, then checks one exact algebraic sample point in each
cell. No floating-point sign test is used for the proof predicate.
\end{certificatecheck}

The finite-enumeration theorem specializes to the following enumeration
problem.
It is exhaustive to consider the two- and three-bounce candidates; all other
combinatorial types are either redundant or cannot realize a smaller action.
In the Lagrangian product
\(P_5{}_q\times_L R(\theta)P_5{}_p\), the relevant facet sequence alternates
between \(q\)-blocks and \(p\)-blocks. We label the \(q\)-facets
\(0,\ldots,4\) and the \(p\)-facets \(5,\ldots,9\), in counterclockwise order
in each factor.

A block is the local facet data for one bounce. It is either one facet or an
ordered adjacent pair of facets inside one factor. For a \(k\)-bounce
candidate, where \(k=2\) or \(k=3\), Sage chooses
\(k\) non-overlapping \(q\)-blocks and \(k\) non-overlapping \(p\)-blocks. It
fixes one \(q\)-block as the first block, orders the remaining \(q\)-blocks and
all \(p\)-blocks, and then alternates \(q\)- and \(p\)-blocks cyclically. The
final raw sigma is obtained by concatenating the facets inside those blocks.
Thus the alternation is block-by-block, not necessarily facet-by-facet.
For code simplicity, the implementation fixes only this cyclic representative
convention and otherwise keeps raw ordered representatives instead of
quotienting by reversals or symmetries. This overcounts rather than
undercounts.

Before solving KKT systems, Sage applies exact transition pruning on the open
half-domain. Same-factor transitions must have nonempty facet intersection.
Mixed \(q/p\)-transitions must also have the positive symplectic transition
sign, and Sage checks that this sign has no interior cut point on the open
half-domain. Thus a pruned-out raw sigma fails a necessary transition condition
throughout the open half-domain. The rest of the Sage computation then
classifies every raw representative that survives this pruning.

\begin{certificatecheck}
\noindent\textbf{Certificate check: finite raw list.}
Using Theorem~\ref{thm:lagrangian-product-finite-enumeration}, the enumeration
stage constructs a raw superset of all two- and three-bounce words needed for
the open half-domain. The transition-pruning stage removes only words that fail
an exact necessary condition throughout \(0<\theta<\pi/10\). The remaining list
is not sampled and not quotiented by symmetry.
\end{certificatecheck}

For each raw sigma that passes the open-domain transition pruning, Sage solves
the KKT system exactly. When a branch exists, this gives rational functions for
the multipliers \(\beta_i\), the quadratic value \(Q_\sigma\), and the action
gap
\[
  \frac{1}{2Q_\sigma} - c_{\mathrm{act}}(\theta).
\]
The script then cuts the open interval at all roots and poles of these
functions. On each resulting cell, signs are constant. Sage checks one exact
algebraic sample point per cell. Thus the strict inequalities
\[
  \beta_i>0,\qquad Q_\sigma>0,\qquad
  \frac{1}{2Q_\sigma}-c_{\mathrm{act}}(\theta)>0
\]
are decided by exact algebraic computation, not by numerical sampling.

The classifier is an ordered chain of proof exits. For each raw sigma, one of
the following accepted cases must occur.
\begin{enumerate}
  \item The KKT system is inconsistent.
  \item \(Q_\sigma\) is identically zero.
  \item The KKT system is singular, but every solution has some multiplier
    forced to be identically zero, so no strictly feasible branch exists.
  \item The action gap is identically zero; this is a tie with the active
    branch, not a lower competitor.
  \item No open cell has all \(\beta_i>0\) and \(Q_\sigma>0\), so the branch is
    nowhere strictly feasible on the open half-domain.
  \item On every feasible open cell, the action gap is strictly positive.
\end{enumerate}
The script also has a manual-review fallback for unrecognized cases. That
fallback is not accepted by the certificate; the script asserts that every
classified raw sigma lands in one of the accepted exits.

\begin{certificatecheck}
\noindent\textbf{Certificate check: fail-closed classification.}
For each surviving raw word, the certificate must either prove that no strictly
feasible branch exists on the open half-domain, prove that the branch ties the
active branch, or prove that its action is strictly larger wherever it is
strictly feasible. The manual-review exit is deliberately not an accepted
status, so an unrecognized case makes the run fail instead of contributing to
the theorem.
\end{certificatecheck}

Together with the active branch, equality holds on every open cell. The path
\(\theta\mapsto K_\theta\) is continuous in the Hausdorff topology, the EHZ
capacity is continuous on convex bodies in this topology \cite{CH2021}, and
the volume is constant. Hence \(\operatorname{sys}(K_\theta)\) is continuous in
\(\theta\). Since the displayed formula is continuous as well, equality on the
open cells extends to the cut points and to the endpoints \(0\) and
\(\pi/10\). This proves the formula on the half-domain. The symmetry reduction
at the beginning of the proof then gives the theorem for all real \(\theta\).
\end{proof}
