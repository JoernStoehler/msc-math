# Corrections and misleading simplifications

**Reviewed:** 2026-10-13. These are scoped corrections to product assumptions, grounded in local documentation snapshots. Docs are not proof of live account/runtime behavior. For runtime disputes, record product/surface/version, exact reproduction, source and date, and classify the issue as documentation error, missing caveat, or version mismatch.

1. **Wrong: “One `SKILL.md` configures ChatGPT chat, Work, Codex, and Claude Code identically.”** Separate surfaces have distinct discovery, deployment, tool, and permission semantics. Sources: [ChatGPT Work and Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex), [ChatGPT Skills](https://help.openai.com/en/articles/20001066-skills-in-chatgpt), [Agent Skills specification](https://agentskills.io/specification); local mirrors: `corpus/articles/openai/chatgpt/chatgpt-work-codex.md`, `chatgpt-skills.md`, `corpus/articles/standard/agent-skills/agent-skills-spec.md`.
2. **Wrong: “Custom GPTs inherit global ChatGPT Custom Instructions or memory.”** OpenAI says GPT conversations do not use saved memory, global Custom Instructions, or prior conversations. Source: [GPTs in ChatGPT](https://help.openai.com/en/articles/8554407-gpts-in-chatgpt); local mirror: `corpus/articles/openai/chatgpt/chatgpt-gpts.md`.
3. **Wrong: “Global Custom Instructions override ChatGPT Project instructions.”** Project instructions override global instructions within that project. Source: [Projects](https://help.openai.com/en/articles/10169521-projects-in-chatgpt); local mirror: `corpus/articles/openai/chatgpt/chatgpt-projects.md`.
4. **Wrong: “An API tool can update ChatGPT account Custom Instructions.”** OpenAI says there is no API for that account UI setting; API messages are a separate mechanism. Source: [Custom Instructions](https://help.openai.com/en/articles/8096356-chatgpt-custom-instructions); local mirror: `corpus/articles/openai/chatgpt/chatgpt-custom-instructions.md`.
5. **Wrong: “The Codex repository alone is complete operational documentation.”** Hosted Codex Skills and AGENTS.md docs contain user-facing guidance and may redirect. The locally acquired tagged source and current docs are separate evidence. Sources: [Codex Skills](https://developers.openai.com/codex/skills), [Codex AGENTS.md](https://developers.openai.com/codex/guides/agents-md); local mirrors: `corpus/articles/openai/codex/codex-skills.md`, `codex-agents-md.md`.
6. **Wrong: “GitHub repository size is shallow-clone transfer size or time.”** GitHub's repository `size` metadata is not a measurement of transfer bytes, checkout disk use, or elapsed time. This package has a measured but environment-specific benchmark; see `evidence/benchmark-details.json` and `evidence/benchmark-original.tsv`. Primary evidence: repository metadata from https://api.github.com/repos/openai/codex is retained in `evidence/codex-repository-metadata.json`; compare its `size` field against separately measured benchmark artifacts. This is an API-metadata/measurement distinction, not an inference-runtime test.
7. **Wrong: “Claude Code never reads `AGENTS.md` natively.”** Current Claude Code docs describe native support from v2.1.277, with session exceptions and precedence/configuration rules; some sessions require v2.1.281+. Verify installed version and effective Project instructions. Source: [Claude Code memory](https://code.claude.com/docs/en/memory); local mirror: `corpus/articles/anthropic/claude-code/claude-code-memory.md`.
8. **Wrong: “Saying ‘think harder’ changes ChatGPT’s reasoning setting.”** Prompt wording is distinct from exposed model/effort controls; available controls depend on plan and workspace. Source: [GPT-6 and other models](https://help.openai.com/en/articles/20001354-gpt-6-and-other-models-in-chatgpt); local mirror: `corpus/articles/openai/chatgpt/chatgpt-model-selection.md`.
9. **Wrong: “Claude Code docs require HTML scraping.”** The docs index links direct `.md` endpoints. Preserve source Markdown. Source: https://code.claude.com/docs/llms.txt; local mirror: `corpus/articles/anthropic/claude-code/claude-code-index.md`.
10. **Wrong: “Remember this” updates global ChatGPT Custom Instructions.** Memory and Custom Instructions have distinct controls, and memory is selective. Sources: [Memory](https://help.openai.com/en/articles/8590148-memory-in-chatgpt), [Custom Instructions](https://help.openai.com/en/articles/8096356-chatgpt-custom-instructions); local mirrors in `corpus/articles/openai/chatgpt/`.
11. **Wrong: “Claude chat and Cowork are always separate modes.”** Anthropic documents a staged move toward a merged Claude chat/Cowork experience; actual availability is account- and rollout-dependent. Source: [Cowork and Chat are one Claude](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude); local mirror: `corpus/articles/anthropic/claude-chat/claude-chat-cowork-merge.md`.
12. **Wrong: “Claude Project instructions definitely require a paid plan.”** The Projects help page says Free users can create up to five projects, while the personalization guide contains inconsistent paid-plan wording about instructions. Check live account UI. Sources: [Projects](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects), [Personalization](https://support.claude.com/en/articles/10185728-understanding-claude-s-personalization-features); local mirrors in `corpus/articles/anthropic/claude-chat/`.

13. **Missing context: project-only memory is not a free isolation upgrade for Work.** The current Projects article says an existing project can change memory mode but Work is unavailable in project-only mode. Check this tradeoff before changing a Work-dependent project. Source: https://help.openai.com/en/articles/10169521-projects-in-chatgpt ; local mirror: `corpus/articles/openai/chatgpt/chatgpt-projects.md`.
14. **Vendor-doc inconsistency: Custom Instructions update timing.** The article explicitly says updates apply to existing conversations, then its history FAQ says reflected only in future conversations. Preserve both statements, distinguish historical records from effective behavior, and don't claim live reload was independently verified. Source: https://help.openai.com/en/articles/8096356-chatgpt-custom-instructions ; local mirror: `corpus/articles/openai/chatgpt/chatgpt-custom-instructions.md`.
15. **Observed interpretation error: the API's 25 MB uncompressed limit is per file.** All three disclosed-layout agent runs misstated it as a total uncompressed-content limit. The source says maximum uncompressed file size. File count and ZIP size are separate limits. Source: https://developers.openai.com/api/docs/guides/tools-skills ; local mirror: `corpus/articles/openai/api/openai-skills-api.md`; raw evaluation outputs are retained in `evidence/decision-evaluation/`.
16. **Missing context: Claude Agent SDK source selection can exclude repo skills.** Current docs distinguish omitted `settingSources` from explicit `[]`. Install/read files through a permitted discovery scope rather than assume filesystem existence enables them. Source: https://code.claude.com/docs/en/agent-sdk/skills ; local mirror: `corpus/articles/anthropic/claude-code/claude-code-docs-en-agent-sdk-skills.md`.
17. **Unsupported surface transfer: Cowork is not Claude Code instruction discovery.** No reviewed Cowork source guarantees automatic reading of CLAUDE.md, AGENTS.md or CLI skill directories. Hand off an explicit repo-reading contract and verify actual access. Sources: https://support.claude.com/en/articles/14479288 and https://support.claude.com/en/articles/14116274 ; local mirrors: `corpus/articles/anthropic/claude-chat/claude-cowork-architecture.md`, `corpus/articles/anthropic/claude-chat/claude-cowork-projects.md`.
18. **Observed loop/attention trap: a delivered async question or final message need not yield user attention.** Pinned Codex source shows async acceptance without an answer, accepted follow-ups clearing pending question UI, and active-goal suppression of normal completion notification. Distinguish required-input state from UI delivery; don't invent answers or prohibited goal pause transitions. Evidence: `evidence/question-source-review.md`, `evidence/goal-source-review.md`, `evidence/model-catalog-review.md`; source tag rust-v0.162.1. The user's UI observations are reported, not independently replayed.

## Runtime evidence policy

The claims above distinguish documentation statements, reported user incidents, independently inspected tagged source, disclosed agent-evaluation errors and acquisition measurements. This package does not include executable ChatGPT, Claude, or Codex product-runtime probes for these claims. Do not relabel documentation as observed runtime behavior.
