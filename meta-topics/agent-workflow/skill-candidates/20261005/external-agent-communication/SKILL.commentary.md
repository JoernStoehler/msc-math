# Maintainer commentary: external agent communication

**Status:** Inactive candidate. This is human review commentary, not additional agent instructions. [SKILL.md](SKILL.md) contains the proposed load.

## Intended use and trigger

The abstract condition is an exchange across independent agent contexts. Codex, Claude Code, Pro and human relay are recognition examples, not separate definitions of the capability.

The loaded file keeps route comparison, sufficient context, delivery semantics, short complete route recipes and return integration together. Ordinary native subagent-tree transport already has a tool contract; this candidate adds no protocol to it. Assignment quality can still matter, but that is not a reason to trigger another transport procedure.

## Review question

Is the independent-context boundary clear enough to cover real exchanges without duplicating built-in subagent transport?
