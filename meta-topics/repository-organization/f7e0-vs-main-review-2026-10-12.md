# f7e0 against main: outcome and maintenance review

Reviewed 12 October 2026, within Jörn's fifteen-minute review window. Frozen
comparison: f7e0 `43d4f8db`, main `185155fe`, common ancestor `844fc5be`.
This reviews the two current snapshots, rather than only the migration against
its older starting point. Main contains a separate preservation checkpoint.

**Assessment:** the topic organization largely fits the stated mixed-artifact
goal. f7e0 is an organization contribution, not yet a complete successor to
current main. Preserve both contributions when assembling the eventual working
branch. A wholesale choice of f7e0 would omit useful main research and workflow
work. This omission is acknowledged as deferred integration, not evidence of
permanent destruction or of failed research.

## Verification and limits

Tree-wide Git comparison and three independent domain reviews covered science,
retention/reproduction and operations. Fresh bounded checks passed: workspace
compilation; 88 Euclidean geometry tests; four exact-polytope tests; focused
producer/shared-method/evaluator tests; inventory, dashboard and graph checks.
An initial shared-method test invocation lacked declared dependencies; the
correct `uv` route passed. No expensive producer, full certificate replay,
remote dataset retrieval or new whole-PDF visual review was performed.

This is a broad consequence/risk review, not line-by-line reading of every
repository file or independent mathematical certification. Main's accepted
research statuses are attributed to its retained agent audits. Reduced human
maintenance time, fresh-client portability and R2 reachability remain unmeasured
or untested. No source fixes or merge were made; this review document is the
only retained project addition from the review.
