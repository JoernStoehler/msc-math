# Flow-graph Rust module

Read the [flow-graph topic account](../../../../../topics/flow-graphs/README.md)
and its [implementation contract](../../../../../topics/flow-graphs/implementation-contract.md)
before changing this algorithm or its thesis-facing claims. The topic owns the
mathematical proof, supported input scope, outcome and evidence ledgers.

This directory owns the rational Rust implementation: `exact_tube.rs` resolves
one closed word, `exact_search.rs` performs exhaustive search, and `words.rs`
owns combinatorial enumeration. The imported `tube-algorithm*.md` notes remain
source evidence, subordinate to the maintained topic account and contract.
