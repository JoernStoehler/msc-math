## Theorem Target For Review

Conditional target, if the exact certificate closes:

```text
At the HKO2024 point in the ten-facet dual-vertex chart, the systolic ratio is
locally maximal modulo translations, scaling, and linear symplectic maps.
```

More explicitly:

1. Work in the listed-row chart
   `K(a) = {x in R^4 : <a_i,x> <= 1, i = 0,...,9}` near the HKO point
   `a0`.
2. Use the facet-major coordinate order in `R^40`.
3. Let `T_sym` be the `15`-dimensional tangent space generated by
   translations, scaling, and the identity-component linear symplectic action.
4. Choose an exact `25`-dimensional slice transverse to `T_sym`.
5. Prove that every nonzero slice direction has a selected branch upper bound
   whose first-order change in `sys` is strictly negative.
6. Conclude local maximality on the quotient in the ten-facet model.

Non-targets:

1. Do not claim raw strict local maximality in ambient `R^40`.
2. Do not claim broad HKO local maximality beyond the ten-facet theorem target.
3. Do not prove a complete first-order evaluator for every nearby polytope
   unless the selected-branch route fails and the heavy fallback is chosen.
4. Do not require a complete catalogue of all HK branches if the selected
   one-sided upper-bound certificate is enough.

## Sufficient Sage Decision Problem

The Sage proof surface should decide a sufficient statement, not an equivalence
theorem. Some inputs are constructed by trusted Sage code from definitions;
some inputs are externally generated witnesses that Sage checks.

A theorem-facing Sage run should produce or check the following data.

### Base Geometry

1. Exact HKO dual vertices in `Q(tan(pi/5))`, where
   `tan(pi/5)` satisfies `t^4 - 10 t^2 + 5 = 0`.
2. Exact volume and exact `D_a volume` row in facet-major `R^40` order.
3. Exact HKO minimum action and exact HKO `sys` value.
4. Exact `15` symmetry tangent generators in `R^40`.
5. Exact rank check: `rank(T_sym)=15`.
6. Exact slice basis of dimension `25`, for example a basis transverse to
   `T_sym`.

Current status:

- Exact geometry, field, symmetry rank, and volume-row support already exist in
  `experiments/hko-local-maximum/theorem/exact-witness/`.
- The current widened representative witness verifies symmetry rank `15`,
  endpoint row rank `5`, midpoint row rank `6`, union rank `11`, and exact
  annihilation of the symmetry tangent directions.
- This is still partial and does not close the theorem.

### Selected Branch Rows

For each selected branch row, the witness should contain:

1. `sigma`;
2. exact base beta `beta0`;
3. exact positivity `beta0_i > 0`;
4. exact closure `sum beta0_i a0_{sigma(i)} = 0`;
5. exact normalization `sum beta0_i = 1`;
6. exact branch action equal to the HKO minimum action;
7. exact full-rank minor data for the closure/normalization matrix, or an
   equivalent exact first-order feasible-section certificate;
8. exact `D_a beta(a0)` derived from the feasible-section constraints, or
   enough exact data for Sage to derive it;
9. exact `D_a action` row for the explicit feasible section;
10. exact `D_a sys` row after combining action and volume.

The Sage assertions should split row validity by row type:

1. Nonsingular positive-beta rows:
   they may be handled either by the usual nonsingular KKT branch formula or
   by the same feasible-section upper-branch method.
2. Singular positive-beta seven-facet rows:
   check explicit feasible-section upper-branch data. These rows must not be
   accepted merely because the f64 diagnostic printed a KKT-derived gradient.
3. Padded-zero or right-active rows:
   not part of the optimistic current route. Only add them if the singular
   positive-beta route fails or if exact row coverage changes.

### Cone And Quotient Checks

Sage should verify:

1. every selected `D_a sys` row annihilates `T_sym`;
2. projected selected rows have rank `25` on the slice;
3. an exact convex-combination certificate puts `0` in the relative interior of
   the convex hull of the projected rows.

A convenient exact certificate is a set of certificate rows with coefficients
`lambda_i` such that:

```text
lambda_i > 0
sum_i lambda_i = 1
sum_i lambda_i g_i = 0
rank({g_i : lambda_i > 0}) = 25
```

where `g_i` are the projected rows. The certificate rows may be all selected
rows or a theorem-valid subset. This proves strict first-order decrease in
every nonzero slice direction.

The exact feasible-section certificate now proves this shape for a selected
26-row subset.

## Proof Tree

The final mathematical proof should use the following implication.

1. Sage verifies the base HKO geometry, the symmetry tangent space, selected
   rows, exact row validity, and the slice-cone certificate.
2. For every selected row `b`, there is a branch or branch family `U_b(a)` such
   that:
   - `sys(a) <= U_b(a)` whenever that branch is valid;
   - `U_b(a0) = sys(a0)`;
   - the verified row is the first-order row of `U_b` at `a0`, or gives an
     equivalent first-order upper-bound statement.
3. The relative-interior convex-hull certificate implies that for every
   nonzero slice direction `h`, some selected row satisfies
   `<D U_b(a0), h> < 0`.
4. The selected branch expansion gives
   `U_b(a0 + t h) < sys(a0)` for small positive `t`.
5. Hence `sys(a0 + t h) < sys(a0)` for every nonzero quotient direction.
6. The symmetry tangent directions are flat because they are generated by
   translations, scaling, and linear symplectic maps.
7. A local slice argument converts the slice statement into local maximality on
   the quotient.

The local implication proof must include a uniformity argument. Direction by
direction negativity is not enough if the branch choice and remainder control
degenerate near the unit sphere. The convex-hull relative-interior certificate
should provide a quantitative margin on the compact unit sphere in the slice;
the branch or family theorem must provide compatible first-order remainders.

### Lemma To Prove And Review

Let `E` be the chosen local slice in the `R^40` dual-vertex coordinates, and
let `a0` be the HKO dual-vertex vector. Fix a partial permutation

```text
sigma = (sigma_1,...,sigma_m).
```

For `a` near `a0`, let `C_sigma(a)` be the `5 x m` matrix whose `i`th column is

```text
(a_{sigma_i}, 1) in R^5,
```

and let

```text
e = (0,0,0,0,1)^T.
```

Assume the witness gives:

1. an exact vector `beta0 in R^m` with `beta0_i > 0`;
2. the exact feasibility equation `C_sigma(a0) beta0 = e`;
3. a subset `I` of `{1,...,m}` with `|I|=5` and
   `det C_sigma(a0)_I != 0`;
4. the complementary subset `J`;
5. the HK2017 action denominator is positive at `(a0,sigma,beta0)`;
6. the local volume function satisfies `Vol(a0)>0`.

Define, for `a` near `a0`,

```text
beta_J(a) = beta0_J,
beta_I(a) = C_sigma(a)_I^{-1} (e - C_sigma(a)_J beta0_J).
```

Then:

1. `beta(a)` is `C^\infty` near `a0`;
2. `beta(a0)=beta0`;
3. `C_sigma(a) beta(a)=e` near `a0`;
4. after shrinking the neighborhood, `beta_i(a)>0` for all `i`;
5. after shrinking the neighborhood again, the HK2017 action denominator
   remains positive, so the HK2017 action formula applied to
   `(sigma,beta(a),a)` is a `C^\infty` function `A_sigma(a)`;
6. if `A_sigma(a0)=c_HKO`, then

```text
sys(a) <= U_sigma(a) := A_sigma(a)^2 / (2 Vol(a))
```

near `a0` in the same ten-facet chart, and `U_sigma(a0)=sys(a0)`.

This lemma is deliberately not a KKT lemma. It only uses feasible HK2017 data
to build an upper branch for `sys`.

The derivative row for the certificate is the ordinary derivative of this
explicit upper branch:

```text
D U_sigma(a0)[h]
```

where `D beta(a0)[h]` is obtained by differentiating
`C_sigma(a) beta(a)=e` and `beta_J(a)=beta0_J`. Equivalently,

```text
D beta_J(a0)[h] = 0,
C_sigma(a0)_I D beta_I(a0)[h]
  = - D C_sigma(a0)[h] beta0.
```

Sage may either verify this derivative from the formula above or verify an
explicit exact linear map `h -> D beta(a0)[h]` satisfying these equations.

### Directional-Derivative Lemma

Let `S` be a finite selected row set. Assume for every `sigma in S` there is a
smooth upper branch `U_sigma` near `a0` with

```text
sys(a) <= U_sigma(a),
U_sigma(a0)=sys(a0).
```

Then for every slice direction `h`,

```text
D^+ sys(a0;h) <= min_{sigma in S} D U_sigma(a0)[h],
```

where

```text
D^+ f(a0;h) = limsup_{t -> 0+} (f(a0+t h)-f(a0))/t.
```

Proof idea to formalize: the inequality `sys <= U_sigma` holds for each
selected `sigma` separately, so taking the limsup gives
`D^+ sys(a0;h) <= D U_sigma(a0)[h]` for each `sigma`; then take the minimum.

### Cone-To-Local-Maximum Lemma

Let `r_sigma` be the projected row representing `D U_sigma(a0)` on the
25-dimensional slice. If the exact certificate proves

```text
0 in relint conv{r_sigma : sigma in S},
span{r_sigma : sigma in S} has dimension 25,
```

then there is an `eta > 0` such that for every unit slice direction `h`,

```text
min_{sigma in S} <r_sigma,h> <= -eta.
```

Since the `U_sigma` are finitely many smooth functions, their first-order
remainders are uniform on the compact unit sphere in the slice. Therefore, for
all sufficiently small `t>0`,

```text
sys(a0+t h) <= min_sigma U_sigma(a0+t h) < sys(a0)
```

for every unit slice direction `h`. This gives strict local maximality on the
slice. The separate symmetry argument transfers this to the quotient-local
statement in the ten-facet chart.

## Sage Construction And Verification Packet

Packet 3 now produces:

1. trusted Sage construction code for source-defined exact objects;
2. generator output for finite candidate choices;
3. Sage assertions that the candidate choices satisfy the theorem-facing
   predicate;
4. machine-readable verification summary;
5. a short human-readable verifier explanation for the thesis companion.

The trusted-code boundary is not simply "Rust generates, Sage verifies".
Different data have different roles.

1. Source-defined exact data:
   Sage may construct data directly from the mathematical definition, with
   sanity checks and optional printed outputs. Examples:
   - exact HKO dual coordinates `a0` from the HKO geometric construction;
   - exact symmetry tangent generators;
   - an exact `25`-dimensional slice basis, if a slice basis is used.
   These are not best treated as externally supplied witnesses. The proof
   obligation is that the Sage construction code matches the LaTeX definition,
   and that the code has enough assertions and sanity checks to make mistakes
   visible.
2. Search-generated finite choices:
   Rust or Sage may generate candidate choices such as selected sigmas,
   minor/fixed-coordinate choices, and a small row subset. These are witnesses.
   The generator is not trusted for theorem use.
3. Candidate verification:
   Sage must assert the predicate `phi(x)` for the candidate witness `x`.
   For the current small-certificate route, `x` should include the selected
   sigmas, minor/fixed-coordinate choices, and optionally f64/debug lambdas.
   Sage should verify:
   - exact `beta0`, positivity, closure, and normalization;
   - exact full-rank minor and induced `D beta(a0)` equations;
   - exact feasible-section `D_a action` and `D_a sys` rows;
   - exact equality `U_sigma(a0)=sys(a0)`;
   - exact symmetry annihilation;
   - exact row rank `25`;
   - exact positive convex-combination certificate.

Implemented shape:

1. Rust exports `candidate-certificate.json`.
2. `construct_exact_witness.sage.py` constructs exact witness values. It may
   solve exact systems; this script is not proof-facing.
3. `verify_feasible_section_witness.sage.py` reloads the witness and asserts
   all proof-facing equations.
4. `verification-summary.json` records the passing exact checks.
