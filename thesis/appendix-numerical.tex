\section{Numerical Implementation}\label{app:numerical}

The algorithms in Section~\ref{sec:algorithms} are stated for
exact arithmetic: predicates such as $\beta_i > 0$ and
$N^\top \beta = 0$ are decided exactly, and the KKT system is
solved without numerical error.
In a floating-point implementation, each of these operations
introduces numerical errors that must be controlled.

This appendix develops the numerical counterpart of the exact
algorithm in four parts.
Section~\ref{app:general-approach} states the soundness goal
and introduces the three-valued predicate framework
for the predicates whose evaluation involves numerical
error.
Section~\ref{app:polytope-combinatorics} identifies
the quantities computed exactly from rational coordinates,
characterizes transition feasibility between facets,
and defines numerical robustness conditions.
Section~\ref{app:svd-step} analyses the SVD-based solution of
each KKT system, including near-singular detection
and dismissal, and the three-valued positivity filter.
Section~\ref{app:accumulated-q-max} describes how the algorithm
combines these verdicts to report a capacity value with
appropriate certainty qualifiers.
