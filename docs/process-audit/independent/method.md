# Independent audit method (before comparison)

Scope: two indexed roots and descendants, cutoff 2026-09-15T16:44:07Z. Audit only; no live intervention, thesis edit, replay campaign, or private-log upload. Author uses selected Astra/low; two bounded parallel audits cover DS decisions and frozen thesis/review evidence. Prior REPORT.md, BRIEF.md and assignment withheld until initial findings freeze.

Independence is limited: this is independent reading/decomposition, not blind outcome prediction. Assignment supplies FAIL and narrow PASS outcomes; coordinator logs contain subsequent interpretations, including Pro comparison and handoff critiques. These are attributed claims and leads, not independent corroboration. Delegates have the same assignment. Do not claim statistical independence between same-family agents.

## Evidence and attribution

Start from objective and observed artifact shortcomings, trace backward to consequential decision opportunities, then assess each opportunity forward using the information available at that time. Distinguish observed choice, supporting contemporary information, uncertainty, plausible alternative and its overhead. A recoverable error is not necessarily the decisive cause of failure. Improved incumbent speed and improved choice of approach are separate benefits.

Coverage is metadata closure, not readable completeness. `coverage.txt` checks all discoverable session metadata, including nested source lineage, against the nine indexed sessions at cutoff. No missing descendants were found. This does not establish completeness of host history, external Pro context or inaccessible logs. Existing indexes truncate messages at 1,800 characters and suppress inherited exact messages: use focused raw events for consequential claims. They omit tool bodies; never infer an absent activity solely from their silence. Many inter-agent message bodies are encrypted (coverage counts retained); children’s visible returns can corroborate some actions but do not reveal hidden instructions. Parent/child event counts include inherited events and are not additive independent-work counts.

Use a small evidence graph in prose: objective → required artifact property → failed/missing property → earlier information/decision → proposed control. Include successful paths so the audit does not punish all work because the final outcome failed. Rank interventions by expected net project value qualitatively, with confidence separately. No numeric causal shares, Shapley values or saved-minute claims: there are no defensible coalition outcomes, matched replays, human-attention measurements or counterfactual performance distributions. Summed token fields can double-count inherited/cumulative usage; tool wait durations overlap authoring and human reading.

## Current primary research used and selected limits

- [AgentRx (Microsoft Research, February/March 2026)](https://www.microsoft.com/en-us/research/publication/agentrx-diagnosing-ai-agent-failures-from-execution-trajectories/) develops constraint synthesis and evidence-backed violation logs before judging a critical failure step. Adopt the auditable intermediate evidence for concrete invariants (source closure, unsupported readiness inference). Do not force this thesis trajectory into a single first-unrecoverable-step label: several paths remained open and utility is graded.
- [Who & When (Zhang et al., 2025)](https://arxiv.org/abs/2505.00212) benchmarks agent/step attribution and reports substantial localization difficulty. Adopt focused candidate-decision inspection and explicitly limited confidence. Its benchmark does not validate causal attribution for this project or this model.
- [Demystifying evals for AI agents (Anthropic, January 2026)](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents) distinguishes task, trial, transcript, grader and outcome. Adopt outcome/artifact checks plus transcript diagnosis, and distinguish a single demonstration from measured reliability. Avoid grading exact tool paths when several good research approaches are possible.

These sources guide method, not thesis facts. No library deployment or generic taxonomy ingestion is needed to apply their useful parts here. Proposed behavioral tests will grade meaningful decisions and work products, include nearby negative cases, and measure overhead; they are not executed in this audit.
