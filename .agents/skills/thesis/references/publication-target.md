# Publication Target

Use this reference when a task depends on what final artifact the project must
produce or which milestone a candidate is meant to serve.

Target a defensible, printed-quality master's thesis whose active reading
surface is `thesis/build/main.pdf`. Keep the thesis self-contained at build
time and intelligible without repository archaeology. Treat source files,
proof notes, experiments, code, data, and review artifacts as support for that
reading surface rather than substitutes for it.

Distinguish the current gate. A chapter candidate, a full PDF for Jörn, a PDF
for Kai, and the handed-in thesis require different evidence. Use
`PROJECT_COMPLETION.md` for current milestone state; do not copy that mutable
state into this skill.

Judge local work by its contribution to the intended artifact and gate. A
polished source file that is absent from the PDF, an exact result the thesis
cannot explain, or a buildable chapter that misleads its reader is not ready
for publication merely because its local production task succeeded.
