# Paper Conventions

- Treat cached paper sources as immutable. Add notes or documentation instead
  of editing the source.
- Prefer obtaining LaTeX source, then Markdown, then PDF when the available
  versions are equivalent. arXiv papers commonly expose source archives through
  the paper's official arXiv page.
- Cache or transcribe only what future work needs. Short documents may justify
  a complete Markdown transcription; for long papers, store source pointers
  and relevant passages rather than a second full copy.
- When citing numbered results, check the numbering in the published version.
  Compiling matching LaTeX source may help, but source and published versions
  can differ.
