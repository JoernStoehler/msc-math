\section{Availability of Code and Data}\label{sec:published-code-data}

At the time of writing, the public development repository for this thesis is
\begin{center}
  \url{https://github.com/JoernStoehler/msc-math}.
\end{center}
This is a living Git repository rather than a frozen archival release, and its
contents may change after submission.  The claims below therefore describe
material tracked in the repository at submission time; the URL is not a
permanent snapshot or a DOI.

The strongest computation-bearing results have proof-facing packets in the
tracked tree.  The HKO packet in
\path{experiments/hko-local-maximum/theorem/} contains the finite witness, the
exact SageMath verifier, its recorded verification summary, and the Rust
programs used to select the witness.  Rust supplies finite choices; it is not
trusted for theorem correctness.  SageMath reconstructs the algebraic objects
and checks the exact predicates stated in
Section~\ref{subsec:hko-local-maximum-computation-with-sagemath}.  Those
predicates imply the theorem only together with the mathematical
upper-function and slice argument given there.

The rotated-pentagon packet is stored under
\begin{center}
  \small\path{experiments/regular-products/}\\[-0.2em]
  \path{pentagon-rotation-formula-proof/}.
\end{center}
It contains the exact SageMath classifier and the recorded full-run transcript
for all \(3340\) finite words left after the mathematical reduction.  Here too,
the program does not replace the proof: the enumeration theorem, the
translation from checked signs to action comparisons, and the continuity
argument remain mathematical inputs.  The repository exposes the finite
computation and its output for inspection, with SageMath's exact arithmetic
and root isolation inside the software trust boundary.

Selected non-proof evidence is also tracked as ordinary repository files.  In
particular, the product-capacity implementation audit retains its \(88\)-row
numerical packet, and the historical first-order experiment retains its
\(12\)-run finite-step panel.  The bounded generated-candidate experiment
retains \(1675\) rows selected before the systolic ratio was computed, the
corresponding \(1675\) evaluated rows, its frozen configuration, and compact
reports.  These records support only the finite experiments described in the
corresponding chapters.  They neither prove a population statement nor supply
evidence for local maximality.

The repository is not a self-contained copy of every dataset used during the
project.  Its artifact registry identifies twelve external snapshots through
twenty-one intended release paths, but those files are not present at those
paths in a plain checkout at the time of writing.  For example, the
\(14336\)-row random/product provenance table is tracked, while the source
random/product datasets and the method-facing invariant table are not.
Consequently, cloning the repository alone does not provide every input needed
to repeat all empirical analyses, regenerate every figure, or reproduce every
reported run.  Packet-local instructions describe available producers and
checks, but compatible software, dependencies, compute resources, and
untracked inputs may still be required; timing and other
environment-dependent fields need not reproduce byte for byte.

No frozen release, public Zenodo record, or DOI for this thesis is claimed
here.  Any archival deposit created later would be a separate, immutable
object whose own public record, inventory, and hashes would have to establish
its contents.  Until such an object exists, the GitHub URL above provides
access only to the living repository and to the finite material actually
tracked there.
