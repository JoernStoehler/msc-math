# Sys-Datascience Workflow Evaluations

Use: durable index for workflow-test packets, fresh-agent probes, A/B launch
tests, replay tests, and adversarial bypass reviews. These packets evaluate
agent-facing material. They are not evidence for `sys`, method-table closure,
or thesis mathematical claims unless later promoted through normal packet
review.

Each evaluation entry should preserve:

- date and objective;
- controlled workspace/material;
- prompt or template used;
- raw response pointer, usually a Codex session JSONL path and subagent id;
- parent interpretation;
- material edits made or no-change verdict;
- remaining risk.

Store one markdown file per coherent evaluation wave.
