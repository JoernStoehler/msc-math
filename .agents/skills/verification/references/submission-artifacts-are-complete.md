# Submission Artifacts Are Complete

## Use When

Use this packet near final handin to check mechanical submission, preservation,
and archive artifacts. It is repeatable prep for `tasks/submit-thesis.md`, not
the final thesis-done declaration.

## Property

The thesis submission and archive package contains every required artifact, and
each external action has an owner or completed record.

## Starter Read Set

1. `tasks/submit-thesis.md`.
2. `tasks/verify-thesis-done.md`.
3. `thesis/submission/README.md` and copied form Markdown/PDF files.
4. Current university letter/checklist supplied by Jörn, if available.
5. Final thesis build output and final repo commit/tag decision.

## Checks

1. Identify the final thesis PDF and source commit/tag.
2. Check university requirements:
   - required forms;
   - printed copies;
   - upload mechanism;
   - USB/CD or other code/data media;
   - signatures and deadlines.
3. Check preservation/archive requirements:
   - chosen non-GitHub preservation target;
   - GitHub final state;
   - Zenodo/arXiv/outreach decisions if promoted into closure.
4. Classify each gap as agent-preparable, Jörn-owned, advisor/Kai-owned, or
   external-clock.
